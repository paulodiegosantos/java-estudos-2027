# Módulo 01 — Fundamentos de Java

## Objetivo
Construir uma base sólida na linguagem Java, compreendendo sua sintaxe, seus recursos fundamentais e a lógica necessária para desenvolver aplicações.

## Conteúdo estudado em cada semana

| Semana | Conteúdo |
|---|---|
| Semana-01 | Ambiente Java, sintaxe, variáveis e operadores |
| Semana-02 | Estruturas condicionais e operadores lógicos |
| Semana-03 | Estruturas de repetição |
| Semana-04 | Métodos e parâmetros |
| Semana-05 | Arrays e manipulação de dados |
| Semana-06 | Revisão geral e desafios práticos |
